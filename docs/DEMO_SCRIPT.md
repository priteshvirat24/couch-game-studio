# Demo video: Couch Game Studio (target 2:45, hard limit 3:00)

**The one idea to land:** anyone imagines a game, says it or draws it, and plays the game *they* made on the TV seconds later. Every scene should show imagination turning into play.

**Recording setup**
- Fire TV footage: the Vega Virtual Device on the Apple-silicon Mac, screen-recorded with QuickTime (File → New Screen Recording, select the VVD window). The rules require visible Fire TV / Vega simulator footage, so keep the VVD window frame visible at least once, ideally on the native splash screen.
- Phone footage: record the phone screen (iOS: Control Center → Screen Recording; Android: Quick Settings → Screen record).
- Edit side by side: phone on the left (about 30%), TV on the right (about 70%).
- Real voices if possible: a kid (with a parent's consent) and a grown-up, to show it's for everyone. Otherwise adults reading the lines work.
- No copyrighted music. The in-game chiptune is generated by the app.

**Before recording**
1. The studio runs on AWS at https://16-171-214-22.sslip.io and `vega/src/config.ts` already points there. In `vega/`: `npm run build` and `vega run-app build/aarch64-release/couchgamestudio_aarch64.vpkg com.couchgamestudio.tv.main` (on an M5 Mac, start the device with `bash scripts/start-virtual-device-one-core.sh` first).
2. Check https://16-171-214-22.sslip.io/api/status: it shows which designer is live and how many Bedrock designs were used today. `"last"` should name the Game Director on Bedrock Mantle after the first game; if it says offline, check AWS credentials before recording.
3. Pre-create 1–2 games so the Family Arcade looks lived-in (the starter games are already there), and play one once so the podium has a score to beat.
4. Have a crayon drawing ready (a simple monster or a pet on white paper works best).
5. Turn **Read aloud** on (TV home screen) for the read-aloud moment.
6. Handy for retakes: `/tv/?game=seed-dino&autoplay=1` opens a game directly.

**Editing tips**
- Lead with the TV. Judges should see Fire TV footage within the first 15 seconds.
- Show the phone and TV at the same moment the game appears. That cause and effect is the "wow".
- Linger a beat on the imagining screen and on the drawing as the hero: those are the emotional moments.
- Keep captions on for every spoken line (accessibility, and many judges watch muted).
- Export at 1080p and upload to YouTube as **Public** (not Unlisted, or check the rules), in English.
